Differences in magnitude between two groups

Beyond the mean

Published

September 9, 2026

The effect sizes that we’ve described in depth in this tutorial have concerned the direction and magnitude of mean relationships between two variables.

However, there are also effect sizes to describe the absolute magnitude of differences between groups (lnM), to describe differences in variability (or heteroscedasticity) between two groups (lnVR and lnCVR) and effect sizes to summarize single-group means and proportions. Extracting data for these effect sizes should be fundamentally similar as the other effect size types that this tutorial was dedicated to. We here briefly discuss these effect sizes, their assumptions, and how to calculate them in R.

Differences between groups

Differences in magnitude

lnM is an effect size that describes the absolute difference between two groups, which is often relevant in evolutionary research where the direction of difference between two populations or species is not of interest relative to absolute magnitude of differences (Nakagawa et al. 2026a). This effect size replaces earlier efforts which took the absolute value of SMD (or ‘folded-normal SMD’).

To calculate lnM, you need the sample sizes (\(n_1\), \(n_2\)), means (\(m_1\), \(m_2\)), and standard deviations (\(sd_1\), \(sd_2\)) for two discrete groups, similar as when calculating SMD or lnRoM effect sizes. Note that there is also a paired version of lnM that requires only 1 sample size (\(n\)) and \(rho\)—the estimated correlation between the two groups. As with other paired effect sizes, since \(rho\) is usually unreported, you can use values of 0.5 or 0.8 (and conduct sensitivity analyses!).

How to calculate

The math of lnM can lead to uncalcaluable values when the means of the two groups are similar. For this reason, this effect size should be calculated with SAFE bootstrapping (Nakagawa et al. 2026b).

Here we’ll calculate lnM with metatools::eff_size. Be sure to set SAFE=TRUE in the function arguments. The SAFE_boots argument indicates how many bootstraps to run (1e6 is default and appears to be a good compromise between accuracy nd speed). SAFE_max_secs is the number of seconds to run before timing out per effect size calculation.

# TESTING:
dat <- data.table(x1 = c(15, 15), x2 = c(15.5, 20),
                  sd1 = c(2, 2), sd2 = c(2, 2),
                  n1 = c(15, 15), n2 = c(15, 15))

out <- eff_size(x1 = x1, x2 = x2, 
         sd1 = sd1, sd2 = sd2,
         n1 = n1, n2 = n2,
         data = dat,
         bind = TRUE,
         effect_type = "lnM",
         SAFE = TRUE,
         SAFE_boots = 1e6,
         SAFE_max_secs = 15)

Using the formulas:
     MSb <- (n1 * n2) / (n1 + n2) * (x1 - x2)^2
     MSw <- ((n1 - 1) * sd1^2 + (n2 - 1) * sd2^2) / (n1 + n2 - 2)
     n0 <- (2*n1*n2) / (n1 + n2)
     sb2 <- (MSb - MSw) / n0
     yi_first <- log(sqrt(sb2) / sqrt(MSw))
     MS_Diff <- MSb - MSw
     Mean_Diff <- x1 - x2
     s_d2 <- (sd1^2/n1) + (sd2^2/n2)
     vi_first <- 1 / (4 * MS_Diff^2) * ((n0/2)^2 * (2*s_d2^2 + 4 * s_d2 * Mean_Diff^2) + ( (MSb^2)/(MSw^2) ) * ((2 * MSw^2)/(n1 + n2 - 2)) )
